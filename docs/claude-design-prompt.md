# KobitoBar — トレイ常駐アプリの UI デザイン

## プロダクト概要

**KobitoBar** は、自作分割キーボード「KobitoKey」のコンパニオン常駐アプリ(Tauri v2 + React + TypeScript)。macOS のメニューバー / Windows のシステムトレイに常駐し、トレイアイコンを左クリックするとポップアップが開く。

ポップアップの役割はひとつ — **開いた瞬間、視線を動かさずに「左右の電池残量」と「キーマップ」が分かる**こと。それ以外の機能は載せない。

## 作ってほしいもの

1. **トレイポップアップ — macOS 版**(画面上端のメニューバー直下、アイコンの真下に開く)
2. **トレイポップアップ — Windows 版**(画面下端のタスクバー右下、アイコンの真上に開く)
3. **トレイアイコン** — macOS 版(テンプレートアイコン: 黒 1 色+アルファのみ、システムがライト/ダークで自動反転。約 18×18pt)/ Windows 版(16×16px 実寸で潰れず、ライト/ダーク両タスクバーで視認できるもの)
4. **デザイントークン** — 色・タイポグラフィ・スペーシング・角丸を CSS カスタムプロパティとして定義(実装移植のため)

各ポップアップは、次の**状態バリエーションをすべて**デザインすること:

- **通常**: 両手接続済み(例: 左 82% / 右 76%)
- **低残量**: どちらかが 20% 以下 → 警告表示(色+アイコンや形の両方で。色だけに頼らない)
- **右手不明**: 左 82% / 右 「--」(右手が左手とリンクしていない間に起きる)
- **完全未接続**: キーボード探索中。電池もライブキーマップも出せない状態の placeholder
- **キーマップのフォールバック**: 実機から取得できないとき、理由の 1 行テキスト+静的画像表示に切り替わる

トレイの右クリックメニューは OS ネイティブ描画のため**デザイン対象外**。

## デザインの方向性

**「ターミナル感のあるサイバーさ × クリーンで洗練」**。第一の参照点は **herdr(https://herdr.dev/)** — AI コーディングエージェント用ターミナルマルチプレクサのランディングページ。実際のターミナルセッション(tmux ペイン)をそのまま UI 言語にしたデザインで、これを**トレイポップアップに翻訳**してほしい。近い系統として Warp / Raycast / Linear のような開発者ツールの洗練されたダーク UI も参考に。ハッカー風の演出に寄せすぎず、余白と整列で品よく仕上げる。

herdr から借りたいデザイン語彙:

- ほぼ黒のダーク背景+ライトグレー/白の高コントラストテキスト。**全面モノスペースフォント**
- プロンプト記号(`❯` / `$`)、タイムスタンプ、パス表記風の小さなメタ情報行
- 状態を示す色付きドット(`●` `○` `◉`)+小文字のステータスバッジ(herdr では `working` / `idle` / `blocked` / `done`)→ KobitoBar では接続状態(`connected` / `scanning`)や電池の充足度に流用できる
- 罫線文字(`─` `┃`)を思わせる細いボーダーでのセクション区切り、tmux のペイン/ステータスバー的な構造

ルール:

- アクセントカラーは 1 色(候補を提案すること)+低残量の警告色のみ。多色にしない
- 等幅数字で桁を揃える。残量は大きな % 数値+バー or ブロックゲージ(`▮▮▮▮▯▯` 風)
- UI 文言: ターミナル感を優先し、ラベル・ステータスを英語小文字(`connected` / `scanning` / `L` / `R` など)へ統一する提案を歓迎(現アプリは日本語 UI)。いずれにせよ日英どちらかに統一すること
- **やらないこと**: グリッチ演出・スキャンライン・ネオン発光の過剰使用、多色グラデーション、マスコットのアニメーション(小人モチーフはトレイアイコンに使ってよいが、動かさない)

## ポップアップの内容仕様

実アプリから渡るデータ(IPC 契約):

- `connected: boolean` — キーボードと BLE 接続中か
- `left / right: 0〜100 | null` — 左右の電池残量。`null` = 不明
- 最終更新時刻(HH:MM)
- キーマップ: 4 レイヤー — `0: DEFAULT` / `1: NUMBER` / `2: SYMBOL` / `3: MOUSE`
  - ライブ取得時: 各キーの x / y / 幅 / 高さ / 回転角と、タップ文字+ホールド文字(例: `SPC` + `layer1`)が来る → SVG のキーキャップとして描画
  - フォールバック時: レイヤーごとの静的 PNG 画像+理由テキスト

レイアウト要件:

- **電池残量が最優先**。開いた瞬間に左右の % が大きな等幅数字で読めること。左右(L/R)の対応が直感的に分かる配置
- **キーマップは同じポップアップ内に表示**(別ウィンドウへ逃さない)。レイヤー切替はワンクリック(タブ / セグメントコントロール)
- キーボードの物理形状: 左右分割・計 40 キー・カラムスタッガード(列ごとに縦オフセット)・左右各 3 個の回転した親指キー。1 キーのラベルは最大 5 文字程度、ホールド機能があるキーは小さく 2 段目表示
  - 参考画像: https://raw.githubusercontent.com/e-sp9/KobitoKey_QWERTY/main/images/layer0.png
- フッターにステータス行(接続状態 / 更新時刻 / キーマップの取得元)
- ウィンドウは透明+角丸カード(OS ネイティブの枠・タイトルバーなし)。現在 324×384px だが、キーマップが判読できるサイズへ**変更してよい**(目安: 幅 360〜440px。トレイポップアップとして節度ある高さに収める)

## OS 別の差分

### macOS 版

- メニューバー直下に下向きに開く。macOS のメニューバー由来ポップアップとして自然な角丸(12〜16px)と余白
- フォント: SF Pro / SF Mono のシステムフォントスタック
- 半透明+ブラー(vibrancy 風)を使ってよい(ソリッドなダークにする選択も可。どちらかを提案として明示)
- メニューバーアイコンは**テンプレート必須**(黒 1 色+アルファ。カラー・グレースケール不可)
- 追加提案歓迎: メニューバーのアイコン横に「82/76」のような常時テキスト表示(macOS のみ可能な機能)

### Windows 版

- タスクバー右下から上向きに開く。Windows 11 のフライアウト(クイック設定・カレンダー等)と並んで違和感のない角丸(8px 前後)・余白
- フォント: Segoe UI Variable / Cascadia Mono
- トレイアイコンはフルカラー可。ただし 16×16px 実寸で判別でき、ライト/ダーク両方のタスクバーで見えること
- タスクバーに常時テキストは出せない(残量表示はポップアップとホバー時ツールチップのみ)

## 技術制約

- Tauri v2 の WebView = 実質ブラウザ。HTML / CSS / インライン SVG で表現できるものに限る(外部サービス・重い JS 依存は不可)
- 成果物は**状態バリエーションを並べた HTML モック**(画面ごとに 1 ファイル)+冒頭にデザイントークンの CSS カスタムプロパティ定義
- フォントは各 OS のシステムフォントスタック、または同梱可能な OSS フォント(JetBrains Mono 等)を使い、どれを使ったか明記
- アニメーションは機能的なトランジション(ゲージの伸縮、レイヤー切替のフェード程度)のみ。装飾アニメーションは不可
